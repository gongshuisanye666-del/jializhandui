1、功能描述：  
当接收到手柄数据时，单片机输出电平给电机驱动板，实现马达的转动，将麦轮以X形连上马达，根据其正常运行时的向量实现米字形八向移动与原地转圈。  
2、开发历程：  
①在10月6日完成手柄通讯后，在10月7日开始进行底盘运动相关功能的实现。  
②拿到麦轮后先将其安装在TT马达上，然后我开始学习麦轮的基础运动学原理，运用矢量合成成功达成基础8向运动的方案。然后我将电机驱动板与单片机连接，将PA0到PA7的引脚设置为推挽输出连接上电机驱动板的A1到D2。完成电路连接与规划后，我开始进行代码的编写。我先建立Motor.c与Motor.h进行封装，为了简化代码，我利用宏定义将写引脚操作宏定义为Write()，并将PA0与PA7的引脚命名为AO1到DO2。然后我创建了11个分别表示不同方向与停止的函数，并将它们包含在头文件中，在main.c中建立运动函数根据手柄传入的按键信息利用多个if-else if 语句判断并执行功能。此时车能根据摇杆进行相应操作，基本功能成功实现。  
3、问题与解决方案：  
问题A：最初时麦伦安装的方向有问题，在进行测试时与推演的结果不一致，之后发现我的方案需要麦轮呈X形分布，改变麦伦安装后成功实现功能。  
4、功能的升级与迭代：  
迭代①：我发现用多个if-else if 语句极为繁琐且难以维护，试想能否用switch-case语句进行替换，同时Motor.c中的11个函数即为类似，因此我想到利用函数指针数组创建转移表`(*move[11])(void)`，将函数地址全部存入改数组中，并将这11个方式在.h中宏定义为对应的0到10，实现封装。在mian.c的运动函数中，先将手柄左侧4个按键的值装到一个uint8_t的数direction中，然后用switch-case语句达到每个direction对应一个运动方向，成功将代码实现简化。  
迭代②：但此时由于左右原地转我设定的为左右肩键，因此依旧要用if语句，并且此时switch依旧比较复杂，我试着看能否进一步简化，一个想法在我的脑子里出现,direction对应一个数，能否让这个数与函数指针数组中的位置对应，达到将direction放到数组[]中直接调用，在AI的帮助下，我学到了查表的方法，建立了一个运动表direction_action[16]将direction的实际占有4位变为0到15这16个值，然后将每个值对应宏定义中的方位，将其余的错误按键组全部设定为STOP  
在调用函数时用`move[direction_action[direction]]()`达到简化效果，对转动采取同样的方法，同样实现效果，此时代码得到极大简化。
